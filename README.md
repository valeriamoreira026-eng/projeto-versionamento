## 📖 **Sobre o Projeto**

Este projeto demonstra a aplicação prática de **Git Flow** e **versionamento** através de um sistema Java interativo. Desenvolvido como parte da disciplina de Qualidade de Software, o sistema inclui funcionalidades completas de autenticação, cálculo e perfil personalizado.

---

## 🎯 **Funcionalidades Principais**

### 🔐 **Sistema de Login e Cadastro**
- ✅ Cadastro de novos usuários
- ✅ Login com validação
- ✅ Confirmação de senha
- ✅ Mensagens de feedback interativas

### 🧮 **Calculadora Personalizada**
- ➕ Operações matemáticas básicas
- 💖 **Mensagens motivacionais exclusivas**
- 🎨 Interface amigável com emojis

### 👤 **Perfil da Desenvolvedora**
- Informações pessoais e acadêmicas
- Hobbies e interesses
- Metas profissionais
- Curiosidades

### ✨ **Sistema Integrado**
- Menu navegável completo
- Fluxo contínuo entre funcionalidades
- Design consistente e profissional
